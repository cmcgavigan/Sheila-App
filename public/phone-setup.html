💅 Sheila — Phone Setup

Scan these with the iPhone’s camera. The whole thing takes a minute or two.

When the server starts it prints lines like Anywhere: (Tailscale) and fallback: (Wi-Fi). Paste whichever you’re using here and the QR codes update automatically. If you opened this page from the running server, it’s filled in for you.

Install Tailscale

Scan to get the Tailscale app, then sign in. The phone must be on the same tailnet as the laptop (sign in with your account, or accept the device-share invite).

App Store: search “Tailscale”.

Tailscale path — order of operations
  1. On the laptop: Tailscale installed, signed in, running.
  2. On the phone: install Tailscale (QR 1), sign in / accept the share, toggle it On.
  3. Paste the laptop’s Anywhere: https://…ts.net address into the box above.
  4. Scan QR 2 to open the app → Add to Home Screen.

Wi-Fi path — order of operations
  1. Phone + laptop on the same Wi-Fi network.
